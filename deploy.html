Option 1 — Netlify Deploy Free Permanent

Deploys your dashboard to a public HTTPS URL. Works from any device, any network, worldwide.

One-time setup (2 minutes):
Go to netlify.com → Create a free account
In Netlify → User Settings → Applications → Personal Access Tokens → New access token
Copy the token, paste below, click Deploy
Click URL to copy • Share with anyone
Option 2 — Cloudflare Quick Tunnel Free Temporary

Creates a public HTTPS URL in seconds. No account needed. URL resets each time you restart.

How it works:
Run START-TUNNEL.bat on your PC. It starts a local server and creates a public URL via Cloudflare. Share the URL with anyone — they can open the dashboard on any device anywhere.
To start the tunnel:
  1. Double-click START-TUNNEL.bat in the LDC folder
  2. A Cloudflare URL will appear in the terminal
  3. Share that URL with anyone on any device
  4. URL stays active while the window is open

Netlify gives you a live public URL instantly
